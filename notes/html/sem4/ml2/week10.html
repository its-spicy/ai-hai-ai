The Story So Far

In the previous lecture we met the shallow neural network: an input layer, one hidden layer containing many neurons, and an output layer. A deep neural network simply has more than one hidden layer. You create a first hidden layer, then a second one, and you can keep stacking as many hidden layers as you like.

Given an input, the structure of the network lets us predict an output. The weights of the neurons are the learnable parameters, and together they define the machine learning model.

Today's question is: how do we train such a network? This is a challenging task because a neural network has a lot of parameters, and every one of them must be tuned.

Think of the network as a huge sound-mixing desk with dozens of knobs. Making noise (a prediction) is easy. Figuring out which knob to turn, in which direction, and by how much, so that the output sounds right, is the hard part. Backpropagation is the clever trick that tells us this for every knob at once.

Anatomy of the Deep Network

Let us summarise the deep network from the previous lecture with a concrete example.

  • Input: x∈R3, that is, 3 features of a data point.
  • First hidden layer: 4 neurons, output vector h1​∈R4.
  • Second hidden layer: 5 neurons, output vector h2​∈R5.
  • Third hidden layer: 3 neurons, output vector h3​∈R3.
  • Output layer: 2 neurons, output vector y∈R2.

The layers are fully connected: every neuron is connected to all the neurons (or inputs) of the previous layer. Every layer except the output also gets a bias neuron (a constant input of 1) whose connections carry the bias weights.

The diagram below shows the structure. To keep it readable, the bias neurons and their connections are not drawn.

Weights and Biases

  • Biases: β0​ belongs to the first hidden layer, β1​ to the second, β2​ to the third and β3​ to the output layer.
  • Weight matrices: Ω0​ connects the input to the first hidden layer, Ω1​ connects layer 1 to layer 2, Ω2​ connects layer 2 to layer 3, and Ω3​ connects layer 3 to the output.

A weight matrix always has (number of neurons in this layer) rows and (number of neurons in the previous layer) columns. That is why Ω0​ is 4×3: 4 neurons here, 3 inputs before.

Quantity Meaning Shape
x input 3×1
Ω0​ input → hidden 1 4×3
β0​ bias of hidden 1 4×1
h1​ output of hidden 1 4×1
Ω1​ hidden 1 → hidden 2 5×4
β1​ bias of hidden 2 5×1
h2​ output of hidden 2 5×1
Ω2​ hidden 2 → hidden 3 3×5
β2​ bias of hidden 3 3×1
h3​ output of hidden 3 3×1
Ω3​ hidden 3 → output 2×3
β3​ bias of output 2×1
y network output 2×1

Note for Review Pro-Tip: Shape-checking is the fastest way to catch mistakes. Count the parameters: weights =12+20+15+6=53 and biases =4+5+3+2=14, so this small network already has 67 learnable parameters. Real networks have millions, which is why a systematic method for gradients is essential.

The Forward Pass

With the sizes fixed, the whole network is defined by four equations:

h1​=a(β0​+Ω0​x)h2​=a(β1​+Ω1​h1​)h3​=a(β2​+Ω2​h2​)y=β3​+Ω3​h3​

Here a(⋅) is the activation function. The output layer uses no activation function, so y is just the linear expression. The input to each layer is the output of the previous one.

Given any input x, we can implement these four equations and obtain the output. This process, which maps x→y, is called the forward pass.

What the matrix multiplication really does (first layer)

For the first layer, Ω0​ is 4×3 and x is 3×1, so the product is 4×1, which matches β0​:

β0​+Ω0​x=⎝⎛​β0,1​β0,2​β0,3​β0,4​​⎠⎞​+⎝⎛​ω11​ω21​ω31​ω41​​ω12​ω22​ω32​ω42​​ω13​ω23​ω33​ω43​​⎠⎞​⎝⎛​x1​x2​x3​​⎠⎞​=⎝⎛​β0,1​+ω11​x1​+ω12​x2​+ω13​x3​β0,2​+ω21​x1​+ω22​x2​+ω23​x3​β0,3​+ω31​x1​+ω32​x2​+ω33​x3​β0,4​+ω41​x1​+ω42​x2​+ω43​x3​​⎠⎞​

Row j of Ω0​ holds the weights of neuron j. Then a(⋅) is applied to each of the 4 entries separately, which gives h1​. The same pattern repeats with shapes (5×4)(4×1), (3×5)(5×1) and (2×3)(3×1) in the later layers.

One compact equation

Substituting each equation into the next, starting from the output:

y=β3​+Ω3​h3​y=β3​+Ω3​a(β2​+Ω2​h2​)y=β3​+Ω3​a(β2​+Ω2​a(β1​+Ω1​h1​))y=β3​+Ω3​a(β2​+Ω2​a(β1​+Ω1​a(β0​+Ω0​x)))

This one equation links the input x, the output y and all the weights. Collect every parameter into a single set:

ϕ={β0​,β1​,β2​,β3​,Ω0​,Ω1​,Ω2​,Ω3​}

so the network is simply a function

y=f(x,ϕ)

Given ϕ and an input, the forward pass produces the output.

Note for Review Pro-Tip: Exams love the question "what are the shapes of Ωk​ and βk​?". Remember: rows = neurons in the current layer, columns = neurons in the previous layer, and βk​ has as many entries as there are rows.

Measuring Wrongness with the Loss Function

Suppose we have a dataset of n points {(xi​,yi​)}i=1n​. For each input xi​, the forward pass gives a predicted output y^​i​. We are solving a regression problem here, so we compare the prediction with the ground-truth output.

Since the outputs are vectors, the comparison uses the squared 2-norm:

ℓ(ϕ)=n1​i=1∑n​∥y^​i​−yi​∥22​=n1​i=1∑n​∥f(xi​,ϕ)−yi​∥22​

Write it as an average of per-sample losses:

ℓ(ϕ)=n1​i=1∑n​ℓi​(ϕ),ℓi​(ϕ)=∥f(xi​,ϕ)−yi​∥22​

Here ℓi​ is the squared difference between the predicted vector and the ground-truth vector for the i-th data point. The loss is a function of the parameters ϕ: change the weights and the predictions, and therefore the loss, change.

The learning task

Given the dataset {(xi​,yi​)}i=1n​, find the optimal parameters ϕ∗ that minimise the loss.

If we can solve this, then for any new input we can compute the predicted output. If the architecture and the optimisation strategy are both good, the accuracy on unseen test points will be high.

Training with Gradient Descent

The question is how to find ϕ∗. We go back to basics and apply gradient descent. We have already seen many variants of it. Whichever variant we choose, all we need is the gradient of the loss with respect to every learnable parameter.

Start from an initial set of weights ϕ0​. (How to initialise the weights of a neural network is discussed later.) At the t-th iteration, let Bt​ be the t-th batch of data. The update is:

ϕt+1​←ϕt​−αi∈Bt​∑​∂ϕ∂ℓi​(ϕ)​∣∣​ϕt​​

where α is the learning rate, and the gradient is evaluated at the current parameters ϕt​.

There are two kinds of parameters, biases βk​ and weights Ωk​, and each has its own update rule. The iteration number is written as a superscript, because there are many β's and Ω's and the subscript k is already taken for the layer:

βkt+1​←βkt​−αi∈Bt​∑​∂βk​∂ℓi​​Ωkt+1​←Ωkt​−αi∈Bt​∑​∂Ωk​∂ℓi​​

Note for Review Pro-Tip: Gradient descent, mini-batch variants, momentum and so on are all interchangeable optimisers. They all consume the same ingredient: ∂βk​∂ℓi​​ and ∂Ωk​∂ℓi​​. Backpropagation is how we produce that ingredient.

The Gradient Problem

So the entire training problem reduces to one question:

Given a neural network and a batch of data points, how do we efficiently find the gradient of the loss with respect to each weight and bias?

The answer is the backpropagation algorithm. You could invent your own method, but backpropagation is the famous, standard one. To understand its idea, we first study it on a very simplified example, and then return to the real neural network.

A Toy Function for Backpropagation

Take a function f with an input x and parameters β0​,ω0​,β1​,ω1​,β2​,ω2​,β3​,ω3​. It has the same nested structure as our network, but every quantity is a scalar, and we choose the activation functions ourselves: sine first, exponential second and cosine third.

f(x,ϕ)=β3​+ω3​cos(β2​+ω2​exp(β1​+ω1​sin(β0​+ω0​x)))

The loss over the dataset is

L(ϕ)=i=1∑n​(f(xi​,ϕ)−yi​)2

with the per-sample loss ℓi​=(f(xi​,ϕ)−yi​)2.

What we need, for k=0,1,2,3, are the partial derivatives

∂βk​∂ℓi​​,∂ωk​∂ℓi​​

because with these we can apply gradient descent directly.

Note for Review Pro-Tip: The choice of activation function is itself a hyperparameter. We pick the one that gives the best performance. However, we should keep in mind the range of the output we expect, and choose the activation accordingly. Sigmoid and ReLU are not the only options, and any differentiable function can serve here.

Why Direct Differentiation Hurts

The easy case, β3​. Since β3​ sits right at the outside of the expression:

∂β3​∂ℓi​​=2(f(xi​,ϕ)−yi​)∂β3​∂f​

Because no other term contains β3​, we have ∂β3​∂f​=1, so

∂β3​∂ℓi​​=2(f(xi​,ϕ)−yi​)

The hard case, β0​. Now consider

∂β0​∂ℓi​​=2(f(xi​,ϕ)−yi​)∂β0​∂f​

Here β0​ is buried deep inside the function: ω3​ multiplies a cosine, which contains an exponential, which contains a sine, which finally contains β0​. It is a composition of multiple functions. Differentiating it analytically in one go gives a long expression:

∂β0​∂f​=−ω3​sin(f2​)⋅ω2​ef1​⋅ω1​cos(f0​)

where f0​,f1​,f2​ are the inner expressions (defined in the next section). For a deeper network this expression grows, and each parameter's derivative would recompute the same inner pieces again and again.

So we need a clever trick to obtain all the gradient values without repeating work.

Breaking the Function into Steps

The toy function looks like a neural network: the output is β3​+ω3​(⋯), with cosine, exponential and sine as the three activation functions. It follows exactly the same equations as before, except that the input and all the weights are scalars and the activations are specified.

So we simplify the calculation by breaking it into parts, one operation at a time:

f0​=β0​+ω0​xh1​=sin(f0​)f1​=β1​+ω1​h1​h2​=exp(f1​)f2​=β2​+ω2​h2​h3​=cos(f2​)f3​=β3​+ω3​h3​

The output is f3​ (we use the name f3​ instead of y for the prediction), and the loss is

ℓi​=(f3​−yi​)2

The computation forms a chain, called the computation graph: x→f0​→h1​→f1​→h2​→f2​→h3​→f3​→ℓi​.

(The diagram is drawn vertically because the chain is too long to fit an A4 page width.)

Now we want all the derivatives of ℓi​ with respect to β0​,ω0​,β1​,ω1​,β2​,ω2​,β3​,ω3​. The tool is the chain rule from calculus.

The Backward Pass

The chain rule idea

If ℓi​ depends directly on f3​, and f3​ depends directly on h3​, then the effect of h3​ on ℓi​ is the product of two simple effects:

∂h3​∂ℓi​​=∂h3​∂f3​​⋅∂f3​∂ℓi​​

Think of it as a blame game. The final error ℓi​ blames f3​ by some amount. f3​ then passes on a share of that blame to h3​, scaled by how strongly h3​ influences f3​. h3​ passes a share to f2​, and so on. Each station only needs to know two things: the blame it received and its own local sensitivity.

Step by step, from the end

Step 1. ℓi​ is a direct function of f3​:

∂f3​∂ℓi​​=2(f3​−yi​)

Step 2. Move one step back to h3​. We already have ∂f3​∂ℓi​​, and the new local derivative is ∂h3​∂f3​​=ω3​ (from f3​=β3​+ω3​h3​):

∂h3​∂ℓi​​=∂h3​∂f3​​⋅∂f3​∂ℓi​​=2ω3​(f3​−yi​)

Step 3. Move to f2​. Since h3​=cos(f2​), the new local derivative is ∂f2​∂h3​​=−sin(f2​):

∂f2​∂ℓi​​=∂f2​∂h3​​⋅∂h3​∂ℓi​​=−sin(f2​)⋅2ω3​(f3​−yi​)

Step 4. Move to h2​. Since f2​=β2​+ω2​h2​, the local derivative is ω2​:

∂h2​∂ℓi​​=∂h2​∂f2​​⋅∂f2​∂ℓi​​=ω2​⋅∂f2​∂ℓi​​

Step 5. Move to f1​. Since h2​=exp(f1​), the local derivative is exp(f1​):

∂f1​∂ℓi​​=∂f1​∂h2​​⋅∂h2​∂ℓi​​=exp(f1​)⋅∂h2​∂ℓi​​

Step 6. Move to h1​. Since f1​=β1​+ω1​h1​, the local derivative is ω1​:

∂h1​∂ℓi​​=∂h1​∂f1​​⋅∂f1​∂ℓi​​=ω1​⋅∂f1​∂ℓi​​

Step 7. Move to f0​. Since h1​=sin(f0​), the local derivative is cos(f0​):

∂f0​∂ℓi​​=∂f0​∂h1​​⋅∂h1​∂ℓi​​=cos(f0​)⋅∂h1​∂ℓi​​

At every step, the factor on the right is already available from the previous step. So each step requires finding only one new gradient: the local derivative between two neighbouring nodes. This is why we start from the end and propagate gradients in the backward direction, hence the name backpropagation.

The gradient computation graph

The gradient graph has 8 nodes: ℓi​,f3​,h3​,f2​,h2​,f1​,h1​,f0​. Moving along the chain, each node's gradient is the previous node's gradient multiplied by the local derivative written on the arrow. The branches to the side are the parameter gradients, explained in the next section.

Note for Review Pro-Tip: This often appears on exams regarding backpropagation. Remember that the intermediate gradients (∂ℓ/∂fk​, ∂ℓ/∂hk​) are only stepping stones. They are computed once, in a single backward sweep, and reused by every parameter that sits at or before that point. Also remember that the local derivatives (like cos(f0​) or exp(f1​)) need the values from the forward pass, so those values must be stored.

From Intermediate Gradients to Parameter Gradients

Our real goal is ∂βk​∂ℓi​​ and ∂ωk​∂ℓi​​. Each fk​ is a direct function of its own βk​ and ωk​, so one more application of the chain rule, branching off the main chain, finishes the job.

Output layer (k=3). Since f3​=β3​+ω3​h3​:

∂ω3​∂ℓi​​=∂ω3​∂f3​​⋅∂f3​∂ℓi​​=h3​⋅2(f3​−yi​)∂β3​∂ℓi​​=∂β3​∂f3​​⋅∂f3​∂ℓi​​=1⋅2(f3​−yi​)

Layer 2. Since f2​=β2​+ω2​h2​:

∂ω2​∂ℓi​​=h2​⋅∂f2​∂ℓi​​,∂β2​∂ℓi​​=∂f2​∂ℓi​​

Layer 1. Since f1​=β1​+ω1​h1​:

∂ω1​∂ℓi​​=∂ω1​∂f1​​⋅∂f1​∂ℓi​​=h1​⋅∂f1​∂ℓi​​,∂β1​∂ℓi​​=∂f1​∂ℓi​​

Layer 0. Since f0​=β0​+ω0​x:

∂ω0​∂ℓi​​=∂ω0​∂f0​​⋅∂f0​∂ℓi​​=x⋅∂f0​∂ℓi​​,∂β0​∂ℓi​​=∂f0​∂ℓi​​

Notice that for ω0​ we do not need to go back along the chain again. We just keep ∂f0​∂ℓi​​ ready and multiply it by ∂ω0​∂f0​​.

The two universal rules

For every layer k=0,1,2,3:

∂βk​∂ℓi​​=∂fk​∂ℓi​​,∂ωk​∂ℓi​​=(input to layer k)⋅∂fk​∂ℓi​​

where the input to layer k is hk​ for k=1,2,3 and the original input x for k=0.

Complete table of gradients

Using δ=f3​−yi​ for brevity:

Parameter Gradient
β3​ 2δ
ω3​ 2h3​δ
β2​ −2ω3​sin(f2​)δ
ω2​ −2ω3​sin(f2​)h2​δ
β1​ −2ω3​ω2​sin(f2​)ef1​δ
ω1​ −2ω3​ω2​sin(f2​)ef1​h1​δ
β0​ −2ω3​ω2​ω1​sin(f2​)ef1​cos(f0​)δ
ω0​ −2ω3​ω2​ω1​sin(f2​)ef1​cos(f0​)xδ

Compare the β0​ row with the expression we got from direct differentiation earlier. They are identical, but backpropagation reached it by reusing earlier results instead of starting over.

Note for Review Pro-Tip: Notice the pattern: deeper parameters have longer products of local derivatives. If any factor in that product is close to 0 (for example cos(f0​)≈0), the gradient of every earlier parameter gets squashed. This observation is the root of the famous "vanishing gradient" issue in deep networks.

Back to the Real Network

The neural network we started with has exactly the same structure as the toy function. The differences are only these:

  • The input x is a vector, not a scalar.
  • The biases βk​ are vectors, not scalars.
  • The weights Ωk​ are matrices, not scalars.
  • The activation function a(⋅) is a general choice rather than sin, exp and cos.

Its computation graph is the same chain:

f0​=β0​+Ω0​x,h1​=a(f0​),f1​=β1​+Ω1​h1​,h2​=a(f1​)f2​=β2​+Ω2​h2​,h3​=a(f2​),f3​=β3​+Ω3​h3​=y,ℓi​=∥f3​−yi​∥22​

The backward pass runs from ℓi​ back to f0​, and every parameter gradient is read off the chain exactly as above. The gradient of a parameter has the same shape as the parameter itself: ∂Ω0​∂ℓi​​ is 4×3, ∂β2​∂ℓi​​ is 3×1, and so on.

Note for Review Pro-Tip: A preview of the vector version, to be worked out in detail when we implement it. The scalar rule "multiply by ω3​" becomes "multiply by Ω3⊤​", and the scalar rule "ωk​⋅hk​" becomes an outer product:

∂f3​∂ℓi​​=2(f3​−yi​),∂h3​∂ℓi​​=Ω3⊤​∂f3​∂ℓi​​,∂Ω3​∂ℓi​​=∂f3​∂ℓi​​h3⊤​

Check the shapes: Ω3⊤​ is 3×2 times a 2×1 vector gives 3×1, which matches h3​. The outer product is (2×1)(1×3)=2×3, which matches Ω3​.

Practice Questions

Question 1 — Re-architecting the network. In the network with layer sizes 3→4→5→3→2 (67 parameters), suppose you insert an additional hidden layer of 6 neurons between the second and third hidden layers. Which of the existing weight matrices and bias vectors change shape, and what is the new total number of parameters? Also, how many extra steps does the backward chain gain?

Question 2 — A dead weight. In the toy function, suppose ω2​=0 at some point in training. Which of the gradients ∂β1​∂ℓi​​, ∂ω1​∂ℓi​​, ∂β0​∂ℓi​​, ∂ω0​∂ℓi​​ become zero? Is ∂ω2​∂ℓi​​ also forced to be zero? Use this to argue whether ω2​ can ever "recover" during training.

Question 3 — A flat spot in the chain. For the toy function, suppose a particular input produces f0​=2π​. Which parameter gradients are guaranteed to vanish for this data point, and which are not? What does this tell you about how the position of a parameter in the network affects its learning signal?

Question 4 — Counting the work. Suppose you computed each of the 8 parameter gradients in the toy function independently, by multiplying out all local derivatives from ℓi​ down to that parameter. Roughly how many local-derivative multiplications would you perform, compared with backpropagation where each intermediate gradient is computed once and reused? Generalise your counting to a chain with L layers. How does the gap grow as the network gets deeper?

Question 5 — Shapes as a guide. In the real network, you know ∂f2​∂ℓi​​∈R3 and Ω2​ is 3×5. Using only dimension matching and the pattern from the output layer, deduce what ∂h2​∂ℓi​​ must look like (its shape and which matrix multiplies which vector), and what ∂Ω2​∂ℓi​​ must look like. Explain why a naive "multiply by Ω2​" cannot be dimensionally correct.
